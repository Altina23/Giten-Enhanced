# Giten Enhanced

Windows版『偽典・女神転生 東京黙示録』を、現代のPCで遊びやすくする非公式拡張パッチです。ウィンドウ表示、キーボード操作、戦闘メッセージ、セーブ・ロードなどを改善します。

**現在の配布版：v0.1.0-preview.5（試作版）**

## ダウンロード

**[試作版のダウンロード・リリース説明](https://github.com/Altina23/Giten-Enhanced/releases/tag/v0.1.0-preview.5)**

リリースページの **Assets** から **Giten-Enhanced-v0.1.0-preview.5.zip** をダウンロードしてください。確認用の SHA256SUMS.txt も掲載しています。

GitHubが自動生成する「Source code (zip)／(tar.gz)」は、パッチの配布ファイルではありません。

### preview.5の主な変更

**機能追加**

- 戦闘：行動できるようになった順に、敵も味方も動くようにしました。CMD を開いている間と、戦闘メッセージを表示している間は、敵も味方も待ちが止まります。
- 戦闘：メッセージの表示中にも 1～6キーで CMD を開き、次の行動を予約できます。予約した行動は、その仲間の順番が来たときに実行します。
- 戦闘：CMD を開いている仲間を黄色い枠で示します。
- 戦闘：左 Ctrl で、戦闘メッセージの早送り（ターボ）を切り替えます。Tab で、戦闘メッセージの記録（ログ）を表示します。
- 戦闘：状態異常、攻撃力などの上下、結界（魔反・物反など）を、仲間の欄に小さな札で表示します。
- 戦闘：射程の届かない技を選んだときは、「攻撃がとどかない！」と表示します。
- 戦闘：能力の上限で重ね掛けできないときに、その旨を表示します。複数の敵への効果は「〜たち」と表記します。
- 敵：戦闘の外で敵が攻撃してきたら、そのまま戦闘が始まります。
- 敵：雑魚の行動を、素早さに応じて速くしました（ボスは変わりません）。こちらへ近づいてくるときの歩みも速くしました。
- 敵：ダンタリオンⅡの強さを、新しい戦闘の速さに合わせて調整しました。
- 画面：戦闘の悪魔や近くの壁・扉を、ぼかさずにくっきり描くようにしました。「設定を変更」の「画面」タブの「悪魔・人物・壁の描画」で、原作の見た目（ぼかす）にも切り替えられます。
- 画面：ダンジョンの移動で、1歩ごとに一瞬止まって見える引っかかりをなくしました。「設定を変更」の「操作」タブでオフにできます。
- 画面：マウスカーソルが札や窓の陰に隠れないようにしました。
- 操作：マウスのホイールを下へ回すと、会話・戦闘結果・レベルアップ・入隊試験の文を送れます。
- 操作：ステータスの EQUIP 欄をホイールで1行ずつ送れます。戦闘の ITEM 一覧の見出しの総数を右寄せにしました。
- 設定ツール：「操作」タブに「デバッグモード」を追加しました（標準はオフ）。オンにすると、SYSTEM にデバッグメニュー（3D移動・戦闘テストなど）が出て、F8 で月齢を進められます（Shift+F8 で戻す）。セーブデータを壊すおそれがあるので、試すときはセーブを分けてください。

**不具合修正**

- 戦闘：テトラザン・トランジオ・炎の壁・水の壁の結果の文が空欄になる問題。「魔法の結界が張り巡らされた」と表示します。
- 戦闘：「必殺の一撃！」の文が一瞬で消えて読めない問題。
- 戦闘：どこでもセーブの窓を開け閉めした後の戦闘で、ゲームが落ちることがある問題。
- 戦闘：戦闘の最後の文の間に開いた魔法・アイテムの一覧が、戦闘後に残って操作できなくなる問題。
- 敵：戦闘の外で、隣のマスにいる敵が攻撃してこない問題（原作の不具合）。
- 画面：中有・高天原などで、3Dの画面が真っ白になる問題（preview.3 から）。

書き換えたゲームのデータ（メッセージ・ダンタリオンⅡなど）は、ゲームEXEと同じく、元のゲームのファイルに差分を当てて作ります。元のゲームのデータは配布物に含みません。

セーブ形式はpreview.4と同じです。今のセーブはそのまま使えます。

戦闘メッセージを早く読み進めたいときは、戦闘中に左 Ctrl で早送り（ターボ）を切り替えてください。読み逃したメッセージは Tab で記録を表示して確認できます。

**重要：** preview.2以降で保存したセーブ（96枠形式）は、preview.1やオリジナル版では読み込めません。戻す場合は、更新前のセーブ（自動バックアップ）を使うか、「設定変更・セーブデータ管理」の「preview.1向けに書き出す」で変換してください。preview.1やオリジナル版のセーブは、そのまま読み込めます。

## このパッチでできること

| 分類 | 主な改善・拡張 |
| --- | --- |
| 画面表示 | DxWndなしでウィンドウ表示。移動・サイズ変更と位置の記憶に対応し、表示領域は640×480未満にならないよう制限します。大きさを変えても縦横比4:3を保ち、拡大しても文字がくっきり表示されます。大きさと全画面の状態も記憶し、起動時の大きさ（等倍・1.5倍・2倍）も選べます。Alt+Enterで全画面に切り替えられます。戦闘の悪魔や壁をくっきり描き、ダンジョンの移動の引っかかりもなくしています。タイトルバーに適用中の版を表示します。 |
| 移動・マップ | WASDで前後移動・左右旋回、Q/Eで横歩き、Spaceでマップを表示します。 |
| 仲間の操作 | 1～6キーで各キャラのCMDを開けます。メッセージの表示中にも次の行動を予約できます。ボス戦、味方への単体魔法の対象指定、DDS召喚位置の選択にも対応します。 |
| 戦闘表示・進行 | 行動できるようになった順に敵も味方も動き、CMD中とメッセージの表示中は待ちが止まります。行動宣言、各ダメージ結果、撃破表示を順番に読みやすくします。左 Ctrl で早送り、Tab でメッセージの記録を表示します。メッセージ欄の背景を暗くし、文字に影を付けます。数値と技・道具の名前を色分けします（オフにできます）。状態異常・能力の上下・結界を札で表示します。 |
| 敵 | 戦闘の外で隣のマスの敵が攻撃してこない原作の不具合を直し、敵が攻撃してきたらそのまま戦闘が始まります。雑魚の行動の速さを素早さに応じて調整しています。 |
| MAGIC／ITEM一覧・DDSウィンドウ | 一覧はホイールでスクロールできます。MAGIC／ITEM一覧とDDSウィンドウは見出しをドラッグして移動でき、位置を記憶します。ITEM一覧には通常アイテム枠の使用数を表示します。 |
| アイテム | 通常アイテムの所持枠を96に拡張します。所持品が満杯のときは装備解除を止めて案内します。 |
| セーブ・ロード | 通常移動中にF6でセーブ、F7でロードのメニューを開けます。従来の端末などのセーブ・ロードも使用できます。 |
| 設定・管理 | 「操作」「戦闘メッセージ」「画面」「セーブ」のタブで、操作キー、メッセージの表示時間と見た目、ゲームの速さ、画面の大きさや描画方式、保存先などを変更できます。既存セーブの検索・一括取り込みにも対応します。テスト用のデバッグモード（標準はオフ）もあります。 |

マウスによる従来の操作も使えます。操作拡張や呼出キーなどは設定から変更できます。

## 適用前に必要なもの

- **未改変のWindows版dds.exeと、ゲームのデータ一式**。PC-98版には対応していません。
- **.NET Framework 4.5以降**。
- 元のゲームとセーブデータのバックアップ。

**DxWnd・DDrawCompat・dgVoodooは不要です。** 必要な描画DLL（拡張パッチ独自のGitenDDraw）はツールが配置します。ゲーム起動時にはDxWndを終了し、パッチ適用先へ別の描画DLLを追加しないでください。元のゲームフォルダーにあるDLLを削除する必要はありません。

配布物には、ゲーム本体・画像・音楽・個人のセーブデータは含みません。

## 初めて使う方

1. 配布ZIPをすべて展開し、**payloadフォルダーを隣に置いたままGitenEnhanced.exe** を開きます。
2. **「新しく適用する（初めての方）」→「適用を開始」** を選び、「オリジナルのdds.exe」を参照します。
3. コピー先を「参照」で指定します。選んだフォルダー内に専用のゲーム環境を作るため、確認画面で実際の作成先を確認してください。短い半角英数字のローカルパスを使ってください。元ゲームの中やその親フォルダーには適用できません。
4. 必要なら「デスクトップにゲーム実行ファイルのショートカットを作成」にチェックを付け、適用します。
5. 続きから遊ぶ方は **「既存セーブ取り込み」** へ進みます。新規に始める方は不要です。

元のゲーム環境は残し、複製した専用環境へパッチを適用します。詳しい手順は同梱のREADME.txtをご覧ください。

### 既存セーブを引き継ぐ

取り込みたいデータにチェックを付け、**「取り込む」** から取り込み先の枠を確認して確定します。1件でも複数件でも同じ操作です。

- 元のセーブは残し、適用先の空き枠へコピーします。使用済みの枠は上書きしません。
- 元ゲームのWindows／VirtualStoreなどの保存先から候補を探します。見つからなければ「ファイルを追加」を使えます。
- 後から取り込む場合も、適用済みのゲームフォルダーを選べば利用できます。再適用は不要です。

## 普段の起動と設定

適用完了画面に表示される**ゲームEXE**、または**デスクトップのゲーム用ショートカット**から直接起動してください。GitenEnhanced.exeを毎回開く必要はありません。

設定変更時はゲームを終了し、ツールの **「設定変更・セーブデータ管理」** を開きます。

- **設定を変更**：次の4つのタブで設定を変更します。
  - 「操作」：1～6キー、移動キー、Spaceのマップ、一覧のホイールとドラッグ、ダンジョンの移動のなめらかさ、デバッグモード。
  - 「戦闘メッセージ」：行動名と結果を見せる時間、色分け、メッセージ欄の背景の濃さ、文字の影。
  - 「画面」：ゲームの速さ、起動時の表示と大きさ、縦横比、拡大の見た目、悪魔・人物・壁の描画、描画方式、表示位置。
  - 「セーブ」：通常移動中のセーブ・ロードとそのキー、セーブの保存先。
- **保存フォルダーを開く／元のセーブ保存場所を開く**：適用先と元ゲームのセーブを確認できます。

設定は次のゲーム起動から反映されます。保存先を変更しても、既存データは自動移動しません。

### どこでもセーブ・ロードの範囲

F6／F7は、戦闘・CMD・会話・マップなどを閉じた**通常の移動画面**で使用できます。戦闘中やイベント中を含め、あらゆるタイミングで呼び出す機能ではありません。

どこでもセーブしたデータは保存時の位置で復帰し、従来のセーブはセーブ部屋の外へ戻す元の座標補正を保ちます。呼出キーの変更や機能の無効化も可能です。

## 更新するには

1. [Releases](https://github.com/Altina23/Giten-Enhanced/releases)から新しい配布ZIPを手動でダウンロードし、別の場所へすべて展開します。
2. **新しくダウンロードしたGitenEnhanced.exe** を開きます。
3. **「更新（適用済みの方）」** に表示された環境が、普段使っている**拡張パッチ適用済みのゲームフォルダー**かを確認し、**「この環境を更新する」** を押します。別のフォルダーを更新する場合は **「別の環境を選んで更新」** から選びます。ZIPの展開先や、元のゲームフォルダーではありません。
4. 更新画面で、必要ならデスクトップにショートカットを作成するチェックを付け、**「更新を開始」** を押します。進み具合は画面に表示されます。

preview.2以前から更新すると、以前の描画DLL（dgVoodoo）をゲームフォルダー内の dgVoodoo_backup へ移します。不要ならフォルダーごと削除してかまいません。

対応する版のセーブと設定を保持して更新します。書き換えたゲームのデータは、ゲームフォルダーの元のファイルに差分を当てて更新します。セーブの再取り込みは不要です。更新前のセーブは、ゲームフォルダー内のEnhancedUpdateBackupsへ自動でコピーし、コピーを確認できない場合は更新を中止します。GitHubからの自動ダウンロードには対応していません。

新しく適用する画面で適用済みのフォルダーを選んだ場合は、更新を案内します。

## 困ったとき・不具合報告

- 表示がおかしいときは、「設定を変更」の「画面」タブで「描画方式」を GDI にすると、GPUを使わない表示に切り替わります。報告の際は、ゲームフォルダーの GitenDDraw.log を添えてください。
- ショートカットが見つからない場合は、管理画面の「ゲームのショートカットを作成」を使ってください。作成できなくても、完了画面のゲームEXEから直接起動できます。
- 元のゲームと取り込み元のセーブは残ります。更新時の旧プログラムの退避とセーブの自動コピーは、プレイ中のセーブを定期バックアップする機能ではありません。大切なセーブは保存フォルダーから別途コピーしてください。
- 不具合は[Issues](https://github.com/Altina23/Giten-Enhanced/issues)、または配布元ブログのコメント欄へご報告ください。Windowsのバージョン、GPU、パッチのバージョン、発生操作、エラー内容があると調査に役立ちます。
- セキュリティソフトに検出された場合は、保護を停止せず検出名を添えてご報告ください。

Windows 11の手元の環境で確認していますが、試作版のため、すべてのPC・場面での動作は確認できていません。各版の変更内容と制限は[リリース説明](https://github.com/Altina23/Giten-Enhanced/releases)をご確認ください。
