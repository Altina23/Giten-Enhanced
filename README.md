# Giten Enhanced

Windows版『偽典・女神転生 東京黙示録』を、現代のPCで遊びやすくする非公式拡張パッチです。ウィンドウ表示、キーボード操作、戦闘メッセージ、セーブ・ロードなどを改善します。

**現在の配布版：v0.1.0-preview.1（試作版）**

## ダウンロード

**[試作版のダウンロード・リリース説明](https://github.com/Altina23/Giten-Enhanced/releases/tag/v0.1.0-preview.1)**

リリースページの **Assets** から **Giten-Enhanced-v0.1.0-preview.1.zip** をダウンロードしてください。確認用の SHA256SUMS.txt も掲載しています。

GitHubが自動生成する「Source code (zip)／(tar.gz)」は、パッチの配布ファイルではありません。

## このパッチでできること

| 分類 | 主な改善・拡張 |
| --- | --- |
| 画面表示 | DxWndなしでウィンドウ表示。移動・サイズ変更と位置の記憶に対応し、表示領域は640×480未満にならないよう制限します。 |
| 移動・マップ | WASDで前後移動・左右旋回、Q/Eで横歩き、Spaceでマップを表示します。 |
| 仲間の操作 | 1～6キーで各キャラのCMDを開けます。ボス戦、味方への単体魔法の対象指定、DDS召喚位置の選択にも対応します。 |
| 戦闘表示・進行 | 行動宣言、各ダメージ結果、撃破表示を順番に読みやすくします。味方・敵の待ち時計を調整し、CMD中は待ちの回復も停止します。 |
| MAGIC／ITEM一覧 | ホイールでスクロールでき、見出しをドラッグして移動した位置を記憶します。 |
| セーブ・ロード | 通常移動中にF6でセーブ、F7でロードのメニューを開けます。従来の端末などのセーブ・ロードも使用できます。 |
| 設定・管理 | 操作、ゲーム速度、メッセージの表示時間、保存先などを変更できます。既存セーブの検索・一括取り込みにも対応します。 |

マウスによる従来の操作も使えます。操作拡張や呼出キーなどは設定から変更できます。

## 適用前に必要なもの

- **未改変のWindows版dds.exeと、ゲームのデータ一式**。PC-98版には対応していません。
- **.NET Framework 4.5以降**。
- 元のゲームとセーブデータのバックアップ。

**DxWnd・DDrawCompatは不要です。** 必要な描画DLL（dgVoodoo）はツールが配置します。ゲーム起動時にはDxWndを終了し、パッチ適用先へ別の描画DLLを追加しないでください。元のゲームフォルダーにあるDLLを削除する必要はありません。

配布物には、ゲーム本体・画像・音楽・個人のセーブデータは含みません。

## 初めて使う方

1. 配布ZIPをすべて展開し、**payloadフォルダーを隣に置いたままGitenEnhanced.exe** を開きます。
2. **「初めての方はこちら」→「適用を開始」** を選び、「オリジナルのdds.exe」を参照します。
3. コピー先を「参照」で指定します。選んだフォルダー内に専用のゲーム環境を作るため、確認画面で実際の作成先を確認してください。短い半角英数字のローカルパスを使ってください。元ゲームの中やその親フォルダーには適用できません。
4. 必要なら「デスクトップにゲーム実行ファイルのショートカットを作成」にチェックを付け、適用します。
5. 続きから遊ぶ方は **「既存セーブ取り込み」** へ進みます。新規に始める方は不要です。

元のゲーム環境は残し、複製した専用環境へパッチを適用します。詳しい手順は同梱のREADME.txtをご覧ください。

### 既存セーブを引き継ぐ

取り込みたいデータにチェックを付け、**「取り込む」** から取り込み先の枠を確認して確定します。1件でも複数件でも同じ操作です。

- 元のセーブは残し、適用先の空き枠へコピーします。使用済みの枠は上書きしません。
- 元ゲームのWindows／VirtualStoreなどの保存先から候補を探します。見つからなければ「ファイルを追加」を使えます。
- 後から取り込む場合も、適用済みのゲームフォルダーを選べば利用できます。再適用は不要です。

## 普段の起動と設定

適用完了画面に表示される**ゲームEXE**、または**デスクトップのゲーム用ショートカット**から直接起動してください。GitenEnhanced.exeを毎回開く必要はありません。

設定変更時はゲームを終了し、ツールの **「設定変更・セーブデータ管理」** を開きます。

- **操作全般・戦闘メッセージ**：操作キー、ゲーム速度、行動宣言・結果の表示時間など。
- **画面・一覧・保存先**：ホイール、一覧のドラッグ、表示位置、セーブの保存先。
- **保存フォルダーを開く／元のセーブ保存場所を開く**：適用先と元ゲームのセーブを確認できます。

設定は次のゲーム起動から反映されます。保存先を変更しても、既存データは自動移動しません。

### どこでもセーブ・ロードの範囲

F6／F7は、戦闘・CMD・会話・マップなどを閉じた**通常の移動画面**で使用できます。戦闘中やイベント中を含め、あらゆるタイミングで呼び出す機能ではありません。

どこでもセーブしたデータは保存時の位置で復帰し、従来のセーブはセーブ部屋の外へ戻す元の座標補正を保ちます。呼出キーの変更や機能の無効化も可能です。

## 更新するには

1. [Releases](https://github.com/Altina23/Giten-Enhanced/releases)から新しい配布ZIPを手動でダウンロードし、別の場所へすべて展開します。
2. **新しくダウンロードしたGitenEnhanced.exe** を開きます。
3. **「手動更新」→「拡張パッチを更新する」** から、普段使っている**拡張パッチ適用済みのゲームフォルダー**を選びます。ZIPの展開先や、元のゲームフォルダーではありません。

対応する版のセーブと設定を保持して更新します。セーブの再取り込みは不要です。GitHubからの自動ダウンロードには対応していません。

今回の版では、自動最小化を防ぐ描画互換設定を更新時に変更します。ほかの設定とセーブは保持し、Alt+Enterによる画面モード切り替えが有効になります。

## 困ったとき・不具合報告

- ショートカットが見つからない場合は、管理画面の「ゲームのショートカットを作成」を使ってください。作成できなくても、完了画面のゲームEXEから直接起動できます。
- 元のゲームと取り込み元のセーブは残ります。更新時の旧プログラムの退避は、プレイ中のセーブを定期バックアップする機能ではありません。大切なセーブは保存フォルダーから別途コピーしてください。
- 不具合は[Issues](https://github.com/Altina23/Giten-Enhanced/issues)、または配布元ブログのコメント欄へご報告ください。Windowsのバージョン、GPU、パッチのバージョン、発生操作、エラー内容があると調査に役立ちます。
- セキュリティソフトに検出された場合は、保護を停止せず検出名を添えてご報告ください。

Windows 11の手元の環境で確認していますが、試作版のため、すべてのPC・場面での動作は確認できていません。各版の変更内容と制限は[リリース説明](https://github.com/Altina23/Giten-Enhanced/releases)をご確認ください。
