# Giten Enhanced

### 偽典・女神転生 非公式互換性改善・機能拡張プロジェクト

1999年に発売されたWindows用RPG『偽典・女神転生 東京黙示録』を、現代のWindows環境で快適にプレイするための非公式改善プロジェクトです。

本プロジェクトでは、最新のWindows環境における互換性の改善に加え、オリジナル版に存在する操作性やゲーム進行上の問題を修正し、各種機能の拡張を行っています。

オリジナル作品の雰囲気を尊重しながら、現代のPCでも自然に楽しめるプレイ環境の実現を目指しています。

**本プロジェクトは非公式のものであり、原作の権利者・関係企業とは一切関係ありません。**

## 主な改善・拡張機能

以下には公開済みの機能に加え、試作・検証段階の機能も含まれます。利用できる機能は各リリースの説明をご確認ください。

### 1. Windows互換性の改善

- 現代のWindows環境での動作改善
- 3Dダンジョンの描画問題への対応
- DxWndを使用しないウィンドウモード
- 描画・ゲーム進行速度の調整
- 各種動作設定の拡張

### 2. ゲーム進行・戦闘システムの改善

- 3Dダンジョンの移動・旋回速度の適正化
- 壁衝突時の効果音の異常な連続再生への対処
- 敵AIの行動ウェイト調整
- バトルメッセージの表示速度改善
- 戦闘時の操作応答・進行テンポの調整

オリジナル版では、現代のPC環境において移動速度や戦闘処理が不自然に高速化する場合があります。

本プロジェクトでは、ゲーム全体の処理速度だけでなく、敵AIやメッセージ表示などの独立した処理も調整することで、自然なプレイ体験を目指しています。

### 3. キーボード操作の改善

- WASDキーによる移動操作
- 数字キー（1～6）によるキャラクターのコマンド表示
- Spaceキーによるマップ表示
- マウス操作への依存を軽減するショートカットの追加

### 4. 利便性の向上

- どこでもセーブ・ロード機能
- ITEM・MAGICウィンドウのドラッグ移動
- 各種設定のカスタマイズ

どこでもセーブ・ロード機能では、従来のセーブ部屋を前提とした復帰座標の補正処理にも対応しています。

なお、特殊なイベント進行中など、すべての状況での動作を保証するものではありません。

## 導入方法

配布ZIPファイルに含まれる説明、および各リリースの導入手順をご確認ください。

## 動作環境・既知の問題

Windowsのバージョン、GPU、グラフィックドライバー、使用する互換DLLの組み合わせによって動作が異なる場合があります。

特定の環境で動作確認できた場合でも、すべての環境での正常動作を保証するものではありません。

既知の問題や動作確認結果については、各リリースの説明およびIssuesをご確認ください。

## 不具合報告

不具合を発見した場合は、GitHubのIssues、または配布元ブログのコメント欄からご報告ください。

- WindowsのバージョンとOSビルド番号
- GPUの型番とドライバーバージョン

- エラーメッセージや再現手順
